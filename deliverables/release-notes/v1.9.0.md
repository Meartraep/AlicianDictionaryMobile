# Alician Dictionary v1.9.0

## 主要更新

- **数据库更新改为启动自动检查**：冷启动初始化完成后自动向 GitHub 拉取发布清单（约 300 字节，失败静默），发现新版本时弹出提示并等待你确认下载；选择「稍后」只记住该版本，下一版才会再次提示。下载带大小与 SHA-1 双重校验，更新前自动备份当前数据库。设置页新增「启动时自动检查」开关、本地数据库版本与最近检查时间。
- **官方日/英译与爱丽丝语原句逐句对齐**：修复翻译器中「同一段落的相邻两句共享整段译文」（A 的翻译含 B、B 的翻译也含 A）的问题，共 95 组 / 218 行；改动 266 行、补齐 3 行。同时修正 4 处上游源文件缺陷：Alice_Music 英译整体错位一段、killed_by_angel S02/S03 英译互换、Wanderers S21–S23 英文跨段、Fehlt 的 `<br>` 残留。
- **背诵模式首启选择字体**：首次进入背诵页先选「爱丽丝语原字体」或「只学拉丁转写」；选拉丁转写会跳过字符入门小测，直接开始背词。
- **翻译引擎按官方日文语料校准**：重新核对 Elize、Zel、end、Loosya 等功能词语义，新增中文词块细分与组合能力，语义扩展默认开启；语法文档补充 4.15–4.19、7.1–7.2 等语料实证章节。

## 修复

- 数据库更新入口不再指向上游全量库（该库不含官方日/英译词，直接替换会丢失译词）；原按钮改为手动「检查并导入上游完整数据库」并补充说明。
- Chaquopy 的 pip 增加 `--no-cache-dir`，修复受限构建环境下写 wheel 缓存失败的问题。

## 验证

- Android 单元测试 37 项通过（含新增 DatabaseUpdateLogicTest 8 项）。
- Python 测试 64 项通过（test_attested_grammar + test_chinese_composition）。
- 逐句对齐强校验：149 个多句段落的切分片段均可逐字拼回官方原文；全库 1279 行重复扫描，相邻重复块 95 → 6（剩余 6 组均为爱丽丝语原句本身相同）。
- 线上清单与数据库实测：size / sha1 完全一致；冷启动决策模拟：老用户（v0）提示更新、全新安装（v1）静默、「稍后」后不再重复提示。

- ABI：arm64-v8a + x86_64
- 数据库资源：内置 `database_metadata` 版本标记（db_version 1），发布清单 `database-manifest.json`

# Alician Dictionary v1.9.0 (English)

## Highlights

- **Database updates are now checked automatically at startup**: after a cold start the app fetches a small published manifest from GitHub (~300 bytes, silent on failure) and, when a newer revision exists, shows a prompt and waits for you to accept the download. "Later" remembers that revision, so the prompt only returns for a newer one. Downloads are verified by size and SHA-1, and the current database is backed up before it is replaced. Settings gained an "auto check at startup" switch plus the local database revision and last check time.
- **Official Japanese/English lyrics now align sentence by sentence**: fixed the translator showing one stanza's whole translation on two adjacent lines (A containing B and B containing A) — 95 blocks / 218 lines, 266 lines corrected and 3 added. Four upstream source defects were fixed as well: the Alice_Music English block shifted by one stanza, killed_by_angel S02/S03 swapped, Wanderers S21–S23 English split across three stanzas, and a stray `<br>` in Fehlt.
- **Study mode asks which script to learn**: on first entry pick "Alician glyphs" (glyph primer + quiz) or "Latin transcription only", which skips the glyph quiz and starts the deck immediately.
- **Translation engine recalibrated against the official Japanese lyrics**: Elize, Zel, end and Loosya were re-checked against the corpus, Chinese chunking/composition improved, and semantic expansions now default to on. The grammar document gained corpus-attested sections 4.15–4.19 and 7.1–7.2.

## Fixes

- The database update entry no longer points at the upstream full database (which carries no official translations and would have wiped them); it is now a manual "check and import upstream full database" action with an explanatory label.
- Chaquopy's pip now runs with `--no-cache-dir`, fixing wheel-cache failures in confined build environments.

## Verification

- 37 Android unit tests pass, including 8 new DatabaseUpdateLogicTest cases.
- 64 Python tests pass (test_attested_grammar + test_chinese_composition).
- Alignment is enforced mechanically: every split fragment of the 149 multi-sentence stanzas rejoins the official source text verbatim; a full 1279-line duplicate scan dropped adjacent duplicated blocks from 95 to 6 (the remainder are lines whose Alician original is identical).
- Live manifest and database verified byte-for-byte (size/SHA-1), and the startup decision simulated: existing installs (v0) get the prompt, fresh installs (v1) stay silent, and "Later" silences that revision.

## Technical details

- Version: 1.9.0 (versionCode 13)
- ABIs: arm64-v8a + x86_64
- Database asset: carries a `database_metadata` revision marker (db_version 1) plus the published `database-manifest.json`
