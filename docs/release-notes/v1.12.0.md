# Alician Dictionary v1.12.0

## 主要更新

### 1. 数据库管理器并入词典

- **词典页新增「数据」工作区**：分页浏览 13 张业务表、精确搜索、按表策展编辑（新增词条/义项、删除预览、字段校验）、引用候选、CSV / SQLite 导出。
- **所有写操作统一走一个数据层**：单连接、写守卫、声明式 schema 校验、操作前恢复点、本地修改台账；危险操作必须「预览 → 恢复点 → 二次确认」。
- **维护动作迁入词典**：重算词频/泛度、重建 `no_class`、白名单全局替换（区分大小写、预览门控）、数据库诊断。
- **设置页收成一张「数据库」卡 + 独立治理页**：版本与身份、检查更新、恢复点回退、手机端发布、整库导入/导出、恢复 APK 内置库、上游完整库来源。
- **修复**：恢复点回退 / 整库导入时 SQLite 连接泄漏导致的文件占用失败；歌词维护只读 `songs.lyric` 唯一正文源。

### 2. 随包数据库升级到 v2

- 删除 19 张零读者的遗留表（12 张词性表 + `test` / `Album1-3` / `Single` / `All_words` / `Unknown`）与 1 条孤儿译文行，并执行 `VACUUM`。
- 业务表 32 → 13；体积 2,854,912 → 2,596,864 字节（约 −252 KiB）；词头 1,339 / 歌曲 53 不变。
- `db_version = 2`（2026-10-29 发布），台账、清单与库内 marker 三者一致；旧库可通过更新提示或「设置 → 数据库 → 恢复 APK 内置数据库」升级。

### 3. 写作助手：蓝词改为「词义不确定」

- 蓝色高亮不再由低词频 / 低泛度决定，改为**词典释义中带 `(?)` 不确定标注的词**（任一义项或词头展示释义命中）；兼容半角/全角括号与问号，普通问号不会被误标。
- 未知词红色优先规则不变；写作页文案、指标卡与侧栏卡片统一改为「词义不确定」。
- 词频 / 泛度不再参与写作助手（不再读取、不再显示），但仍用于背诵排序、词典详情、翻译打分与维护重算。
- 在词典编辑器或数据管理器里为释义增删 `(?)` 后，写作助手立即生效，无需重启。
- 当前数据库 1,339 个词头中有 **184 个**带 `(?)` 标注。

## 安装说明

- 绝大多数 Android 手机请下载 `arm64-v8a` 包；模拟器与 x86 Chromebook 下载 `x86_64` 包。装错架构会提示「应用未安装」。
- 从 v1.11.0 覆盖安装无需卸载，应用数据与本地数据库保留。
- 升级后如果收到数据库更新提示，建议更新以获取 db v2；也可以在治理页「恢复 APK 内置数据库」手动切换。

## 技术细节

- 版本号：1.12.0（versionCode 16）
- ABI：arm64-v8a、x86_64（各一个已签名 APK）
- 数据库：db_version 2（2026-10-29，本版本首次随包发布）
- 验证：Python 256 passed（含写作助手 8 项新测试）；Android 55 个单元测试通过；模拟器实测写作助手 3 蓝 / 1 红 / 1 黑，数据库管理、治理页与恢复内置库 v2 均无崩溃。
