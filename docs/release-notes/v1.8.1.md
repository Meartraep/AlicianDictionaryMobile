# Alician Dictionary v1.8.1

## 修复

- **词典精确搜索不再闪退**：开启「精确匹配」查询词典中未收录的词时，拼写纠错建议会触发列表渲染异常，应用直接闪退。原因是后端建议载荷使用的是 `words`（数组），而客户端读取的是 `word`（字符串），导致每条建议的词都解析成空字符串；Compose 列表以该字段作为 key，出现重复 key 后抛出异常。现已在后端补充 `word` 字段、客户端同时兼容两种字段，并对建议列表使用唯一 key 且过滤空项。
- **页面标题与副标题不再重叠**：设置页、背诵页顶部的大标题与下方说明小字曾互相压印。这两个页面的内容都放在 `LazyVerticalGrid` 中，而 `LazyGridMeasuredItem` 会把同一个 item 内的多个直接子组件放在同一坐标（item 高度取子组件最大值），与 `LazyColumn`（高度累加、依次排布）的行为不同。现将标题与副标题显式包进 `Column`，横屏与竖屏均恢复正常。
- **UI 设置预览卡片正确刷新**：修改主题、配色或字型后，Material 预览卡片未及时更新，现已补充 key 使其正确响应设置变化。
