# Alician Dictionary v1.8.0

## 特别致谢

本版本的歌词与词典英/日资料来自 [alicianlabs](https://github.com/kyuhubb/alicianlabs)（作者 **kyuhubb**）。

衷心感谢作者对爱丽丝语歌词官方英译/日译与词典词义资料的整理与公开，本版本得以在中文释义之外提供官方英译、官方日译与官方韩译的逐句对照，并依据官方词典为 954 个词条补充英文与日文释义。

## 新增

- **歌词译文升级**：完整歌词与例句支持五种译文逐句对照 —— 中文翻译、中文对译、官方日译、官方英译、官方韩译
- **词典英日释义**：与 alicianlabs 官方词典逐词比对，954 个词条补充英文/日文释义，词典结果按 中/英/日 展示
- **官方韩译入库**：Maharajah、A Little Servant、Elysion's Old Mans 三首官方韩译
- 新增 `词典词义对照_不同.txt`（仓库根目录）：与 alicianlabs 词典比对后词义确实不同的条目对照表

## 修复

- 修复完整歌词界面中焦点段落的整段外框被拆散的问题
- 词典词义比对口径调整：仅将两种释义完全无关的词条判为不同，并输出对照表供核对

## SLSA

本发布由 GitHub Actions 构建并生成 SLSA 出处证明（intoto attestation），详见 Release 附件中的 `*.intoto.jsonl`。
